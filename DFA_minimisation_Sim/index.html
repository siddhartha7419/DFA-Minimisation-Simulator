DFA Minimisation Method

What the simulator does at each stage.

01
Remove unreachable states

Only states reachable from the start state can affect the language.

02
Initial partition

Split the reachable states into final and non-final groups.

03
Refine partitions

States stay together only if each symbol leads to the same partition.

04
Repeat until stable

Continue splitting groups until another pass makes no changes.

05
Build quotient DFA

Replace every equivalent group with one state and map its transitions.
